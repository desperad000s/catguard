Watching the keyboard.

Fn is dashed because the keyboard handles it itself. Windows never sees it, so catguard cannot see or block what Fn does.

Try it

Put your flat hand on three or four neighbouring keys. The keyboard locks, the sound plays, and you type human to get it back. Keys you press light up here, so you can see what catguard sees.

What the cat did

Settings

Sensitivity

Sound

Plays when the keyboard locks and again on every further pawstep. No sound is proven for every cat, so pick the one yours dislikes.

Unlock word

Typed blind while the keyboard is locked. Three to twelve letters, nothing a cat would walk.

Start with Windows

catguard starts in the tray when you sign in, without opening this window.

Appearance

The lock window is always dark, so that it is unmistakable.
